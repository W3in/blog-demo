# Blog demo

Rails API + Nuxt frontend + PostgreSQL, all run through Docker. You only need Git and Docker installed.

## Run

```bash
cp .env.example .env
docker compose up --build
```

| Service | URL |
| --- | --- |
| Frontend | http://localhost:3000 |
| Backend | http://localhost:3001 (`/up` health check) |
| Mailpit (dev mail inbox) | http://localhost:8025 |
| PostgreSQL | localhost:5432 |

## Notes for developers

- Development images are `backend/Dockerfile.dev` and `frontend/Dockerfile.dev`. `backend/Dockerfile` is the
  production image generated by Rails and is kept for the deploy stage.
- Containers run as your own user (`UID`/`GID` in `.env`), so generated files are not owned by root.
- Run one-off commands inside the stack, for example: `docker compose run --rm --no-deps backend bin/rails -v`.

Commands used to create the apps (run once, from the repo root):

```bash
# Rails API (--skip-git: do not create a nested git repo inside backend/)
docker compose run --rm --no-deps backend rails new . --api --database=postgresql --skip-git --force

# Nuxt app
docker compose run --rm --no-deps frontend npx nuxi@latest init . --force --packageManager npm --no-gitInit
```

Warning: `rails new --force` overwrites `backend/Dockerfile`. Do not re-run it once the app exists.
